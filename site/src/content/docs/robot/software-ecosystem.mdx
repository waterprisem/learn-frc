<WhyItMatters>
The first time you write `new TalonFX(1)`, VS Code may underline `TalonFX` in red even though your code is correct. The class lives in a library your project does not have yet.
Knowing where robot code gets its pieces from turns that error into a one-minute fix.
</WhyItMatters>

## WPILib is the foundation

**WPILib** is the free, official FRC library and toolset. It gives your project the robot loop, the command-based framework, joystick and NetworkTables classes, control math such as PID, and the simulator.

The installer also sets up VS Code with the WPILib extension, a Java JDK, the Gradle build system, and tools such as AdvantageScope. Installing is a one-time job on each laptop: lesson R.1 walks through it.

WPILib does not know about any specific company's motor controllers, sensors, or cameras. Those come from vendors.

## Vendor libraries add hardware and features

A **vendor library**, or **vendordep** (vendor dependency), is a library from the company that makes a device. It is described by a small **JSON** file in your project's `vendordeps/` folder. When you build, Gradle reads that file and downloads the library.

The template project for the labs has these files:

| File in `vendordeps/` | Library |
|---|---|
| `Phoenix6-26.2.0.json` | CTRE Phoenix 6 |
| `PathplannerLib-2026.1.2.json` | PathPlanner |
| `AdvantageKit.json` | AdvantageKit |
| `REVLib.json` | REV Robotics |
| `WPILibNewCommands.json` | WPILib's command-based framework |

PhotonLib (the PhotonVision library) is not in that template. You add it when you reach the vision lessons.

## Which library is for what

| Library | Made by | You use it for | When you meet it here |
|---|---|---|---|
| **WPILib** | FIRST and the community | The robot loop, commands, controllers, NetworkTables, simulation | Everywhere, starting in track 2 |
| **Phoenix 6** | CTRE | `TalonFX` motors, `CANcoder`, Pigeon 2 | Lesson 2.7, then every mechanism lab |
| **PathPlannerLib** | The PathPlanner project | Autonomous paths and `AutoBuilder` | Lesson 8.1 |
| **PhotonLib** | PhotonVision | Reading camera and AprilTag results | Lesson 7.1 |
| **REVLib** | REV Robotics | Spark motor controllers | Not taught. Older team code uses it. |
| **AdvantageKit** | Team 6328 | An advanced logging framework | Awareness only |

<GoDeeper title="tools are not libraries">
AdvantageScope, Phoenix Tuner X, and the Driver Station are apps that run on your laptop. They are not vendordeps, and your robot project does not import them. AdvantageScope (an app) and AdvantageKit (a library) have similar names and are different things.
</GoDeeper>

## Do it for real

<DoItForReal tools="VS Code with the WPILib extension">

1. Open a robot project in VS Code.
2. Open the command palette and run **WPILib: Manage Vendor Libraries**.
3. Choose **Install new libraries (online)** and paste the library's JSON URL, which is listed in the vendor's documentation.
4. Build the project once so Gradle downloads the library.

**You know it worked when** a new `.json` file appears in `vendordeps/` and the red underlines on that library's classes are gone.

**On a real robot, also check** that the library's version matches the firmware on your devices. Phoenix Tuner X shows the device firmware.

</DoItForReal>
