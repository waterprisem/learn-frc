<WhyItMatters>
Simulation proves your logic. Deploying puts that same code on the roboRIO so real motors move.
Once you know the few clicks and the three or four ways it fails, a deploy takes under a minute.
</WhyItMatters>

## Before you start

- A robot project that builds in VS Code with the WPILib extension.
- A powered robot with the radio and roboRIO on.
- Driver Station open on the laptop.

## Connect to the robot

Pick one way to reach the roboRIO. Only one is needed.

1. **Radio Wi-Fi:** join the robot's network from the laptop.
2. **Ethernet:** plug into the radio's spare port.
3. **USB:** plug a USB cable into the roboRIO's USB device port.

Then check the team number. Open `.wpilib/wpilib_preferences.json` in your project and confirm `teamNumber` is your team's. WPILib uses it to find the roboRIO.

## Deploy

1. Open the Command Palette (Ctrl+Shift+P, or Cmd+Shift+P on Mac).
2. Run **WPILib: Deploy Robot Code**. You can also right-click `build.gradle` and choose **Deploy Robot Code**.
3. Watch the terminal. A **Build Successful** message means the code compiled and was sent, and the RioLog opens to show the robot program's console output.
4. In the Driver Station, wait for **Robot Code** to turn green.

Do not power off the robot while it is deploying. An interrupted deploy can corrupt the roboRIO filesystem and force a re-image.

## What changes compared with simulation

Only the simulated physics stops. Your subsystems, commands, and NetworkTables topics are the same. AdvantageScope now connects to the robot instead of the simulator.

## If something goes wrong

| What you see | Likely cause | Fix |
| --- | --- | --- |
| Terminal says it cannot find or connect to the roboRIO | Laptop is not on the robot network | Rejoin the radio Wi-Fi or plug in Ethernet or USB, then deploy again |
| Same message, and the network is fine | Wrong `teamNumber` | Correct it in `.wpilib/wpilib_preferences.json` |
| Red errors and no **Build Successful** | Compile error in your code | Fix the first error listed, then deploy again |
| Deploy fails with a version complaint, or Robot Code never turns green | roboRIO image and WPILib version do not match | Re-image the roboRIO with the same year's imaging tool |
